# Data sources

`adrs_raw.json` holds Architecture Decision Records copied from three public
repositories, all under the MIT License:

| Project | Repository | Licence |
|---|---|---|
| MoJ Cloud Platform | https://github.com/ministryofjustice/cloud-platform (`architecture-decision-record/`) | MIT, Copyright (c) 2018 Ministry of Justice |
| MoJ Modernisation Platform | https://github.com/ministryofjustice/modernisation-platform (`architecture-decision-record/`) | MIT, Copyright (c) 2020 Crown Copyright (Ministry of Justice) |
| GOV.UK on AWS | https://github.com/alphagov/govuk-aws (`docs/architecture/decisions/`) | MIT |

Each record keeps a link to its original file. `questions.json` (the evaluation
set) was written for this project.
